# Diabetes Classification System

## Project Overview
This project implements a machine learning model for diabetes classification **built entirely from scratch**, without using automated ML pipelines or high-level libraries for core functionality. Key components include:

- **Manual implementation** of data preprocessing and feature scaling
- **Custom-built logistic regression** algorithm with sigmoid activation
- **Web interface** for real-time predictions via Flask
- **Interactive HTML dashboard** displaying classification results

## Technical Implementation
### Core ML Components (Built from Scratch)
- Data normalization/scaling functions
- Logistic regression training algorithm
- Sigmoid activation implementation
- Prediction threshold optimization

### Web Application Features
- Flask backend serving the ML model
- HTML/CSS frontend for user interaction
- Input validation for clinical parameters
- Visual prediction results display

## Key Differentiators
✔ **Educational Focus**: Demonstrates fundamental ML concepts by implementing core algorithms manually  
✔ **Full-Stack Integration**: Combines low-level ML with production-grade web deployment  
✔ **Transparent Process**: All mathematical operations are explicitly coded for learning purposes  

## Technology Stack
- **Machine Learning**: Python (NumPy, Pandas)
- **Web Framework**: Flask
- **Deployment**: Docker (containerized solution)

## How to Run
1. Clone the repository
2. Run the Flask app: `python app.py`
3. Access the interface at `http://localhost:5000`

> **Note**: This implementation prioritizes educational clarity over production optimization, making it ideal for understanding the foundational mathematics behind logistic regression.
